# Screenshot Folder

This folder contains the required submission screenshots for the SMD assignment:

1. `01-local-project.png` - Screenshot showing your project folder/files on your local computer (e.g. in VS Code or Android Studio / File Explorer).
2. `02-expo-qr.png` - Screenshot showing the Expo QR code after running `npx expo start` in your terminal.
3. `03-updated-ui.png` - Screenshot of your application running on a mobile device / emulator / web browser displaying the updated UI and features.
4. `04-github-actions.png` - Screenshot showing the GitHub Actions workflow successfully completed with green checkmarks on GitHub after pushing.
